# spec-bootstrap — новый проект

Используй один раз на проект: когда корпуса ещё нет или он — это
россыпь файлов без структуры. Проект не пустой, есть что
инвентаризировать — это работа уровня `stage`.

## Порядок

1. **Инвентаризация** (если файлы уже есть): `scout` по корню смотрит,
   что за файлы, какие форматы, что из этого источники (в `inbox/`),
   что черновики (в `spec/`), что мусор. Кандидатов на удаление покажи
   владельцу списком, молча не удаляй.
2. **Раскладка.** Создай недостающее по раскладке из контракта: `spec/`,
   `inbox/` с `inbox/done/` для отработанных оригиналов, `wiki/` нужен
   только если есть Confluence. Образцы владельца («возьми за основу»,
   «это шаблон») живут в `spec/_reference/`.
3. **Профиль — `spec/_STRUCTURE.md`.** Инсталлер уже посеял его с
   умолчаниями ядра в секции «Голос»; секции «Структура» и «Вопросы»
   заполняются здесь. Согласуй с владельцем до
   написания документов. Состав секций «Структура» и «Голос» — тот же,
   что снимает `tz-adapt` с чужих образцов, плюс проектные соглашения:
   статусная модель (`draft → review → approved`), нумерация требований,
   имена файлов (латиница-слаги или кириллица — выбери одно и запиши).
   Есть образцы в `spec/_reference/` — абзацы «Голоса» выписываются из
   них дословно; нет — согласуй голос с владельцем до массового письма,
   иначе его переизобретёт каждый документ. Секция «Вопросы» — это
   проектные добавки к банкам `tz-elicit`.
4. **Опорные документы.** `spec/00-обзор.md` (что за проект, системы,
   роли, ссылки), `spec/глоссарий.md` (термин — определение — источник),
   `spec/решения.md` — это реестр решений владельца строками «дата ·
   вопрос · решение», на которые ссылается поле `decisions` паспорта
   документа.
5. **Связывание.** Все созданные страницы связаны `[[wikilink]]`-ами от
   `spec/00-обзор.md`. Прогони `link-check`.
6. **Фиксация.** Профиль структуры — это однострочник в
   `memory/MEMORY.md`. Если структура чужая, заказчикова, профиль живёт
   в `memory/structures/` (skill `tz-adapt`).

## Правила

- Пустых заглушек «на будущее» не порождай: раздел появляется, когда
  есть что писать. Пустая структура — это `_STRUCTURE.md`, а не десять
  пустых файлов.
- Кириллица в именах папок и файлов допустима, но выбор делается явно:
  смесь кириллицы и транслита в одном корпусе — это дефект.
